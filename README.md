# AFU Welland 智能体脂秤 iOS 客户端 (AntAfouScale)

一款基于 SwiftUI 构建的极简、高颜值且无广告的智能体脂秤 iOS 客户端，支持与沃莱（Welland / Fitdays / Icomon）协议的智能体脂秤进行蓝牙连接，实时同步测量数据，并提供多维度身体指标计算及家庭成员管理功能。

安卓项目地址https://github.com/maoziban/smart-body-scale-android

---

## 🌟 功能特性

- **⚡ 秒速蓝牙连接**：支持在后台自动搜寻符合 `AFU-WL` 广播特征的体脂秤，设备开机即连，支持掉线自动重连。
- **📏 高精度体重解析**：采用独创的 3-byte 原始报文逆向算法，将精度提升至小数点后两位（如 `82.05 kg`），实现与秤端屏幕完全同步。
- **📊 8 大核心指标评估**：利用生物电阻抗 (BIA) 科学公式，全方位评估身体健康状况：
  - **BMI**（身体质量指数，精确至二位小数）
  - **体脂率 & 体脂量** (%) / (kg)
  - **肌肉率 & 肌肉量** (%) / (kg)
  - **骨骼肌率 & 骨骼肌量** (%) / (kg)
  - **体水分率 & 水分量** (%) / (kg)
  - **蛋白质率 & 蛋白质量** (%) / (kg)
  - **骨量率 & 骨质量** (%) / (kg)
  - **皮下脂肪率 & 皮下脂肪量** (%) / (kg)
- **👥 家庭成员智能识别**：支持多成员共同使用。在每次测量锁定后，根据历史称重范围自动归属数据到相应成员；若检测到体重差异过大，则会智能提示添加新成员。
- **📝 一屏掌握测量历史**：
  - 支持本地轻量级持久化存储，无网络占用，隐私绝对安全。
  - 测量历史支持侧滑删除，并支持点击进入**单页详情页**——在一屏内将所有 7 个维度指标与体重/BMI 极简整合展示，无需多余滑动。
- **🔒 会话防重过滤**：引入会话级状态机锁定机制。每次上秤锁定的稳定数据只录入一次，彻底杜绝体脂秤连续重复发送稳定包造成的冗余记录产生。

## 📱 运行截图与视觉设计

本项目严格遵循现代 iOS 设计规范，采用莫兰迪蓝绿渐变、毛玻璃质感、微动效卡片等视觉风格：
- **测量首页**：上半部分为当前设备连接状态与超大实时体重，下半部分在稳定后动态渲染卡片。
- **历史记录**：清晰的时间轴列表，直观体现成员归属和体重变动趋势。
- **详情弹窗**：左右双栏排列，一屏收纳全部维度。

## 🛠️ 技术实现

- **SwiftUI**：声明式 UI 框架，支持流畅的动态过渡和极简代码结构。
- **CoreBluetooth**：通过封装的 `ScaleManager` 继承 `CBCentralManagerDelegate` 与 `CBPeripheralDelegate`，订阅 FFB0 服务的 `FFB2` 特征进行数据监听。
- **Combine & AppStorage**：响应式状态绑定，成员与历史数据均通过 `JSONEncoder` 持久化存储在 `UserDefaults` 中。

## ⚙️ 逆向协议参考 (AFU-WL/Welland)

本客户端通过接收 `FFB2` 特征通知的 20 字节原始十六进制报文（例：`AC 29 00 69 40 82 02 00 05 40 ...`）进行解析：
- **报文头**：`0xAC` (第 0 字节)
- **MAC 地址**：第 1-6 字节 (例：`29:00:68:69:40:82`)
- **稳定标志**：第 6 字节为 `0x02` 表示数值锁定已稳定
- **阻抗/ADC**：第 8-9 字节为 Big Endian 格式阻抗 (例：`0x0540` = 1344 Ω)
- **体重算法**：
  $$\text{weight (kg)} = \frac{(\text{raw}[3] - 0\text{x}68) \times 65536 + \text{raw}[4] \times 256 + \text{raw}[5]}{1000}$$

## 🚀 快速上手

### 环境要求
- Xcode 14.0+
- iOS 16.0+
- 物理真机（用于调试蓝牙功能）

### 运行步骤
1. 使用 Git 克隆本项目到本地，或直接在 Xcode 中打开 `体脂秤.xcodeproj`。
2. 确保在 `Signing & Capabilities` 中配置了您的开发团队签名。
3. 连接您的 iOS 设备，选择目标设备并运行 (Cmd + R)。
4. 开启手机蓝牙，光脚站在体脂秤上使其开机，App 即可自动完成首次配对与同步。
